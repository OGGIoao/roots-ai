# 前沿

> 前沿技术怎么进入知识库。原则: **技术为纲, 厂商为索引**。各家在同一批技术问题上竞争, 按技术放最清楚; 想沿着某一家读, 用档案卡。

## 三层

| 层 | 在哪 | 做什么 |
|---|---|---|
| 1. 单元里的 "前沿对照" | 每个 🔥 单元的最后一节 | 先讲原理并在小模型上实现, 再并排对比各家做法 |
| 2. 厂商档案卡 | [labs/](labs/README.md) | 每家一页, 按时间列出每代模型带来了什么, 每条链接到单元 |
| 3. 前沿雷达 | [radar.md](radar.md) | 带日期的流水账; 新东西先登记, 能核实、确实重要时再升级进单元 |

## 核实规则

- 数字和架构细节以技术报告、模型配置、源码为准; 二手文章只用来找线索。
- 能用 [解剖台](anatomy/README.md) 读真实配置的, 一律读出来核对。
- 跑不了的 (比如只支持数据中心 GPU 的推理框架) 只读源码, 讲义里写明。
- 没测过的写 "没有数据"。
