# 知识库 · 后训练

> 预训练好的语言模型, 怎么再训练成你想要的样子: 监督微调、LoRA、偏好对齐、用强化学习优化一个分数。总目录见 [library/README.md](../README.md#后训练-post-training)。

## 单元

| 顺序 | 单元 | 状态 |
|---|---|---|
| 1 | [tool-finetune](tool-finetune/README.md) 监督微调与 LoRA: 让 0.5B 只输出小车的工具调用 | 🟡 待改造 |
| 2 | rl-for-lm 把语言模型当策略做强化学习 (下表 P1) | ⬜ |
| 3 | dpo 偏好对齐 (下表 P2) | ⬜ |
| 4 | grpo 用小车任务的成败作奖励 (下表 P3) | ⬜ |

**前置**: 知识库 [miniGPT](../llm/minigpt/TUTORIAL.md); 第 2~4 单元还需要 [强化学习](../rl/README.md) 的 PPO。

## 和主线的关系

主线 v0.5 用监督微调 (第 1 单元) 让 0.5B 小模型学会输出小车的工具调用。监督微调只教"照着示范说", 不教"哪种说法更容易让小车成功"。第 2~4 单元补这一块: 以 Agent 评测里的成功与否作为奖励, 用 GRPO 继续训练, 看工具调用成功率能提高多少。

## 计划的三个案例

| 案例 | 问题 | 方法 | 规模 |
|---|---|---|---|
| P1 让 miniGPT 学会一个可验证的目标 | 监督学习只能模仿, 怎么让模型去优化一个分数 | 把语言模型当策略做 RL (REINFORCE / PPO) | 知识库 minigpt 训练出的模型 |
| P2 偏好对齐 | 没有明确分数, 只有"这个回答比那个好" | DPO | 0.5B + LoRA |
| P3 提高工具调用成功率 | 用小车任务的成败作为奖励 | GRPO | 0.5B + LoRA, 显存需在测量平台实测 |

P1~P3 是规划时的编号, 写成单元后用目录名。
