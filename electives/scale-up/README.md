# 规模化与上云 (选修)

> 主线全部在一台 8GB 显存的笔记本上完成。这里是笔记本**实测**撞墙之后的方向。状态: ⬜ 未开始。

## 原则

只在笔记本实测撞墙 (显存溢出、要跑好几天) 之后才上云, 并把撞墙的数字写进讲义。上云的部分按对照实验来写: 笔记本 vs 云 GPU、单卡 vs 多卡, 让读者看到"为什么需要多卡", 而不只是"换了台机器"。云 GPU 按小时租用, 用完就关。

## 计划的方向

| 方向 | 笔记本能做到哪 | 需要上云的部分 |
|---|---|---|
| 把模型做大 | miniGPT 量级, Shakespeare 语料 | 真实语料上预训练约 1 亿–10 亿参数的模型; 多卡训练 (DDP / FSDP / ZeRO); scaling law 实测 |
| 后训练 | 0.5B + LoRA 做 DPO / GRPO | 全参数或更大的模型 |
| 推理服务 | 主线 C3 的本地推理服务 | 手写迷你推理服务 (分页 KV、连续批处理、量化) 的并发压测 |
| 机器人仿真 | MuJoCo 单环境 | 大规模并行环境、Isaac Lab 等 Windows 跑不通的工具链 |
