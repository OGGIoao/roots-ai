# 后训练 (选修)

> 把语言模型当作策略, 用强化学习和偏好数据继续训练它。
> 前置: 主线 E4 的 PPO, 以及主线 A2 / C2 里训练或微调出的模型。状态: ⬜ 未开始。

## 和主线的关系

主线 C2 用监督微调让 0.5B 小模型学会输出小车的工具调用。监督微调只教"照着示范说", 不教"哪种说法更容易让小车成功"。后训练正好补这一块: 以 C4 评测里的成功与否作为奖励, 用 GRPO 继续训练, 看工具调用成功率能提高多少。

## 计划的三个案例

| 案例 | 问题 | 方法 | 规模 |
|---|---|---|---|
| P1 让 miniGPT 学会一个可验证的目标 | 监督学习只能模仿, 怎么让模型去优化一个分数 | 把语言模型当策略做 RL (REINFORCE / PPO) | 主线 A2 的 miniGPT |
| P2 偏好对齐 | 没有明确分数, 只有"这个回答比那个好" | DPO | 0.5B + LoRA |
| P3 提高工具调用成功率 | 用小车任务的成败作为奖励 | GRPO | 0.5B + LoRA, 显存需在测量平台实测 |

编号用 P (Post-training), 避免和主线章节号撞号。
