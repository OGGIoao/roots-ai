# 基座线 roots-lm — 自己从零训一个小模型

> 一切的根。小车、学习助教、推理服务, 以后做别的, 都可以基于它延伸。设计见 [FRAMEWORK.md](../FRAMEWORK.md) 第 3 节。状态: ⬜ 未开始。

所有阶段用**同一套代码**, 每个阶段发布检查点和实测报告。每学完知识库的一个单元, 就把对应的部件装到这个模型上, 测前后变化。

| 阶段 | 规模 | 在哪跑 | 做什么 | 状态 |
|---|---|---|---|---|
| **1 本地** | 几千万参数 (先实测再定) | 笔记本 | 全流程跑通: 数据 → 分词 → 预训练 → SFT → DPO / GRPO → 量化 → 自己的推理引擎 | ⬜ |
| **2 上云** | 几亿到十亿参数 | 云 GPU | 同一套代码放大, 得到能用的小基座 (上云计划见 [cloud-plan.md](cloud-plan.md)) | ⬜ |
| **3 前沿部件** | 同上 | 本地或云 | MoE、混合注意力、MTP、新优化器等逐个装上, 和不装的版本对比 | ⬜ |
| **4 长眼睛和耳朵** | 同上 | 本地或云 | 接视觉和语音, 做成小号视觉语言模型或全能模型 | ⬜ |

**说明**: 自己训的模型通用能力会远弱于 Qwen 这类模型。项目里窄任务 (小车指令、工具调用、格式抽取) 用自己的模型, 需要通用能力时用开源模型, 两者对比本身就是教学内容。

**用到的知识库领域**: 阶段 1 主要是 [基础](../library/foundations/README.md)、[大语言模型](../library/llm/README.md)、[后训练](../library/post-training/README.md); 阶段 4 是 [多模态](../library/multimodal/README.md)。
