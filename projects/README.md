# 项目

> 把知识库做成别人用得上的作品。每个项目是一条 "造东西" 的主线, 一站一个能用的版本; 每站只讲 "做了什么、怎么跑、实测结果", 原理链接到 [知识库](../library/README.md)。设计见 [FRAMEWORK.md](../FRAMEWORK.md) 第 5 节。

| 项目 | 做出来是什么 | 主要用到的领域 | 练的技能 | 状态 |
|---|---|---|---|---|
| [① 小车](car/README.md) | 听得懂话的玩具车, v0.1 → v1.0 | 硬件、具身、强化学习、Agent、多模态 | 物理 AI 与端侧推理 | v0.4 仿真版 🟡 |
| [② 学习助教](tutor/README.md) | 能回答本知识库问题、出题、判练习的助手 | Agent (检索、记忆、落地、评测)、后训练 | Agent 落地与数据管线 | ⬜ |
| [③ 推理服务](serving/README.md) | 用自己写的推理引擎部署基座模型和开源小模型, 压测、量化、优化 | LLM 推理与部署、基础 F4 | 推理优化 | ⬜ |
| ④ 领域后训练 (第二批) | 选一个窄领域, 把小模型训专, 配完整评测 | 后训练、评测 | 微调与后训练 | 基座线到阶段 2 后再开 |

**候选** (项目 ①②③ 各做出第一个版本后再决定): 机械臂 (补上抓取和 VLA 的真机部分)、端侧推理 (车上或板上直接跑小模型)、[四足机器人](../electives/quadruped/README.md) (现在是选修)。

所有项目都可以基于基座线 [roots-lm](../base/README.md) 延伸: 窄任务用自己的模型, 需要通用能力时用开源模型。
